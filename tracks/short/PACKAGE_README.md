# 10일 예측 모델

실행 및 재학습 명령은 REPRODUCE.md를 따릅니다. 모든 계산 설정은 config.json에 있으며, 학습은 2020–2024 자료만 읽습니다. 모델은 고정 ExtraTrees / HistGradientBoosting 예측, 정적 혼합, 변동성 감쇠, 고정 배율과 명절 규칙을 사용합니다. 추론 중 추가 학습이나 온라인 잔차 보정은 수행하지 않습니다.

validate_2020_2024.py는 현재 고정 설정을 2022·2023·2024 전진 검증 폴드에서 평가하고 배율의 수치 계산을 확인합니다. validation_2020_2024.json은 그 결과입니다. 이 검증은 방법·윈도우·혼합비율의 탐색 또는 최초 선택 이력을 재현하는 절차가 아닙니다. 배율 계산과 조정 후 점수에 같은 검증 폴드가 사용되므로 독립적인 최종 성능 추정값으로 해석하지 않습니다. 검증 특징 구현과 저장 모델 재학습의 차이는 JSON의 diagnostic_scope에 설명했습니다. 반분산 조정과 변동성 감쇠의 MAPE 최적성을 주장하지 않으며, 양파 배율은 평균 잔차 중심화가 아닌 고정 배율입니다.

입력 관측은 사례별 폴더에 기준일보다 엄격히 이전인 행만 저장합니다. 공휴일은 관측값이 아닌 공식 달력 입력이며, 원본 2025 달력만 포함합니다. 입력 원본 메타데이터와 가공 내역은 입력 ZIP의 source_metadata/ 및 input-manifest.json에 있습니다. v11_zero_linux 후보: weights.joblib은 이 패키지의 train.py를 네이티브 Linux x86_64(Ubuntu 24.04.4, WSL2, Intel Core Ultra 7 265KF), CPython 3.14.8 일반 GIL 빌드, requirements.txt 지정 패키지에서 실행해 2020–2024 자료로 새로 학습하고 split_slim.py로 이 트랙이 읽는 은행만 남긴 파일입니다. 학습 데이터, config.json의 설정·규칙, 코드와 입력 자료는 v11_zero와 동일합니다. 이 트랙의 600개 예측은 v11_zero 제출본과 동일합니다.
